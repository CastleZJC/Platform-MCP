MCP 接入指南
Claude Code 接入 Platform-MCP 的配置步骤、可用工具、使用建议与常见问题
远程服务器部署（streamable-http）推荐
  1. 获取 API Key
    登录 Platform-MCP 管理台，进入「个人设置 → API Key」查看并复制（pmcp_ 前缀，每人一把；admin 可在用户管理页重置）。
  2. 写入 Claude Code 配置
    编辑 ~/.claude.json，在 mcpServers 下新增 Platform-MCP 节点。
  3. 配置连接参数
    url 指向平台 MCP 服务地址，请求 Header 携带 PLATFORM_MCP_API_KEY。
  4. 重启 Claude Code 会话
    重开会话后 Claude Code 自动连接并发现全部 MCP 工具。
  5. 验证连通
    让 Claude 调用 list_datasources，能返回数据源列表即接入成功。
# ~/.claude.json —— mcpServers 下新增 Platform-MCP 节点 { "mcpServers": { "Platform-MCP": { "url": "http://192.0.2.20:9000/mcp", "transport": "http", "headers": { "PLATFORM_MCP_API_KEY": "<your-api-key>" } } } }
本地开发调试（stdio）仅限本机
# ~/.claude.json —— Claude Code 以子进程拉起 MCP Server { "mcpServers": { "Platform-MCP": { "command": "python", "args": ["-m", "platform_mcp.mcp_server"], "env": { "PLATFORM_MCP_ENV": "dev", "PLATFORM_MCP_API_KEY": "<your-api-key>" } } } }
使用建议
场景示例指令Claude 行为
执行 SQL 文件 执行数据库是测试环境，文件 /tmp/init.sql 匹配 UAT 数据源，读取文件后先做风险识别，再逐语句执行并汇总结果
SQL 文本校验 先校验这条 SQL：DELETE FROM t validate_sql 返回风险等级与风险原因，不实际执行
查看可用数据源 列出当前可用的数据源 list_datasources 按角色与所属组过滤返回
远程执行命令 在 linux-app-dev 上执行 df -h execute_command 按 Shell 风控分级，HIGH 需 confirm_token 确认
传输文件 把服务器上的 /tmp/a.log 下载下来 download_file 校验路径白名单，敏感路径强制二次确认
Skill 生态 在广场搜索 ETL 相关的 Skill search_skills 语义搜索广场，可添加至我的个人库
  • HIGH / CRITICAL 操作需 confirm_token 二次确认（一次性令牌防重放），确认与放弃均写入审计。
  • PROD 环境仅 admin 可用；多语句含 HIGH/CRITICAL 在 PROD 直接拒绝。
  • SQL 超 5000 字符或多语句超 3 条自动转异步执行，凭 execution_id 轮询（30 分钟有效）。
  • SQL 文件仅允许白名单目录下的 .sql 文件，禁止路径穿越与符号链接。
  • 33 个 MCP 工具按角色过滤：admin 33 / developer 30 / 一般用户 19。
  • 个人库未过审 Skill 仅本人可用；广场涉库/涉服务器 Skill 对一般用户不可见。
  • 全链路审计：pmcp_audit_log + pmcp_mcp_call_log 双表留痕可追溯。

环境要求
  • Python 3.11.9（平台服务端运行版本）
  • PostgreSQL 16.4（系统库）
  • Oracle Instant Client 11.2 64-bit（连接 Oracle 目标库时需要）
  • 平台账号与 API Key（admin 创建账号时自动生成）
  • 支持 MCP 的 Claude Code 版本
常见问题
个人设置页可查看、复制、重置自己的 API Key；admin 可在用户管理页为任意用户重置，重置后旧 Key 立即失效。
本机调试且能直接运行平台代码时用 stdio（子进程模式）；远程服务器部署或多客户端共用时用 streamable-http（每请求独立鉴权）。
HIGH/CRITICAL 操作会返回 confirm_token 与风险原因；将 confirm_token 随原参数重试即可继续执行（一次性令牌，5 分钟内有效）；确认与放弃均写入审计日志。
MCP 工具按角色动态过滤：一般用户无 database/server 执行类工具，developer 无审核类工具；个人黑名单与涉库/涉服务器可见性规则也会过滤 Skill 搜索结果。
PROD 数据源仅 admin 角色可用；多语句含 HIGH/CRITICAL 在 PROD 直接拒绝（MULTI_STMT_HIGH_RISK）；服务器写入系统目录判 CRITICAL，不接受执行。
